## Readme ##

### To Run the program ###

You first need to install and activate a PostgreSQL database

To run the code:

In the Backend directory

1. run sign_up.py and enter ThaiKorner's url: https://www.thaikorner.com.au/ (This will sign a restaurant up)
2. run the QuestionGen.py server. 
(As long as the server is running, you will be able to generate a quiz for any signed up website)

In the Frontend directory

1. run the quiz.html file in your web browser and enter the name of one of the signed up restaurants
2. Wait approx 30 seconds for the questions to load once you click submit.
3. Click the start button to take the quiz once it appears

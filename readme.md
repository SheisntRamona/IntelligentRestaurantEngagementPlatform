## Readme ##

### To Run the program for test restaurant ThaiKorner ###

You do not need to make any changes, the code will work as is
You will need to install and activate a PostgreSQL database

To run the code:

In the Backend directory

1. run sign_up.py and enter ThaiKorner's url: https://www.thaikorner.com.au/
2. run the QuestionGen.py server. 
(As long as the server is running, you will be able to generate a quiz for any signed up website by editing restaurant name in the script.js file as mentioned in the user manual)

In the Frontend directory

1. run the quiz.html file in your web browser
2. Wait approx 30 seconds for the questions to load (you can check if the questions have loaded using your browser's inspector)
3. Take the quiz
